# bits releases

Official binary releases for **bits**, a local-first bill-of-materials tool for engineers and their agents.

Application source is private. This repository contains release notes and downloadable binaries only. The source archives GitHub adds automatically contain this README, not the application source.

After the first release, install on macOS or Linux with Homebrew:

```sh
brew install harisrab/tap/bits
```

Windows, macOS and Linux archives and checksum-verifying installers are available from this repository's Releases page.
